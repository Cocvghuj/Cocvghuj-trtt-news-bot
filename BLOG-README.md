# TRTT Voyage Blog — Writing Guide

This repository contains an additive blog preview and editorial sample. The existing root `README.md`, root `index.html`, and `blog/index.html` were preserved; this guide is separate to avoid overwriting existing content.

## Where things live
- `trtt-blog-home/index.html` — standalone, static blog-home preview.
- `posts/` — editorial posts and drafts.
- `images/README.md` — image asset rules and folder purpose.

## How to write a post
1. Create a uniquely named file in `posts/`.
2. Write public-facing content in clear English.
3. Put the title, useful introduction, descriptive headings, practical details, and FAQ where relevant.
4. Verify every factual claim against current primary or official sources before presenting it as news or advice.
5. Label estimates and opinions clearly; never invent prices, schedules, tests, quotes, or source links.
6. Use only owned, licensed, or otherwise authorized images. Include meaningful alt text.
7. Add the TRTT editorial marker `787950` where the publishing template requires it.
8. Add a disclosure near the top whenever affiliate links are used.
9. Check internal links, mobile layout, spelling, and accessibility before review.
10. Keep drafts separate from published content. A Git commit does not publish to Blogger.

## Editorial principles
Truth before traffic. Security before automation. Quality before speed. Check official sources for changing travel requirements and include publication/update dates only when verified.

## Status
This is a repository guide and preview. It does not configure Blogger, publish a live post, or deploy a website.
