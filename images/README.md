# TRTT Voyage image assets

This directory is reserved for images used by the standalone blog preview and future posts.

- Add only images owned by TRTT or used with documented permission/licensing.
- Use descriptive, lowercase filenames.
- Provide meaningful alt text in every published page.
- Optimize dimensions and file size before adding assets.
- Do not use remote placeholders or guessed image URLs.

No image asset is included in this initial setup. The folder is tracked by this README.
